# Security & Privacy Policy

## Reporting Security Issues

If you discover a security vulnerability or sensitive data leak in this repository, please do **NOT** open a public issue. Instead, report it privately to the maintainers.

## Privacy & Competition Integrity

This repository is designed for mathematical modeling methodology learning and open research:
- **No Private Data**: All raw competition participant datasets, school identifiers, and author credentials have been audited and excluded.
- **Sanitized Paths**: No host machine absolute paths or usernames are retained in this repository.
- **Fair Competition**: This toolkit provides algorithmic methods, structural templates, and quality verification tools. Users are responsible for adhering to the ethical guidelines and competition rules of their specific contests.
