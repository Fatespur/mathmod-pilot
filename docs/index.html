2026 年版 CUMCM 标准 LaTeX 模板

专为全国大学生数学建模竞赛打造的现代化排版引擎。内置纯匿名电子提交与打印双模切换，解决传统模板标题摘要间距过大、字体混杂等痛点。

  • 纯匿名电子提交模式：第 1 页直入论文题目与摘要，无承诺书、无编号页、无目录，符合匿名审查。
  • 标准字体与字号规范：正文小四号宋体 (SimSun)，标题黑体 (SimHei)，英文与数学公式统一为 Times New Roman。
  • 紧凑优雅的行距控制：标准 1.25 倍行距，段首缩进 2 字符，标题与摘要垂直间距紧凑自然。
  • 一键编译环境：支持 MiKTeX / TeX Live + XeLaTeX 编译，附带 Windows 一键批处理脚本。

PH1–PH3 提交安全与合规治理体系

全自动化审计、白名单文件准入与加密签名，确保 100% 匿名合规与零违规取消资格风险。

PH1 H1-B 深度匿名扫描

递归扫描 PDF/DOCX 属性、修改者、批注、修订轨迹、隐藏文本 (w:vanish) 及图片元数据，杜绝个人/学校/队号泄漏。

PH1 H1-C 白名单打包门禁

采用纯声明式白名单准入，仅打包经授权的论文 PDF、官方 Excel 结果表与源码，自动过滤临时缓存与编译产物。

PH1 H1-E 加密签名防篡改

在终审封存时刻生成交付物 SHA-256 哈希清单并执行 Ed25519 签名，确保封存产物不可篡改且具备完整溯源链。
