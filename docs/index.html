Why MathMod-Pilot?

A dynamic plugin architecture that covers the full CUMCM/MCM pipeline — from problem analysis to paper review.

🔌

Dynamic Plugin Architecture

Skills are discovered at run-time. Drop a folder with SKILL.md + skill.py into the skills directory — no registration code needed.

🔄

Generate-Verify-Revise Loop

The mle-solver iteratively generates code, runs it, captures errors, and revises until all hard assertions pass — fully autonomous.

mle-solver: Generate-Verify-Revise

The computational heart of MathMod-Pilot — an iterative self-correction loop that runs until all hard assertions pass.

⚙️

Generate

Translate the mathematical model into executable Python code — regression, optimisation, ODE solving, evaluation methods.

🔍

Verify

Run the code and check three layers: S1 hard assertions, physical consistency, and model-reality cross-validation.

🔧

Revise

Feed captured errors back into Generate. The loop continues until all assertions pass or max revision count is reached.

↻ Iterates until all hard assertions PASS

Quickstart

Get started in three lines of Python.

# Install
pip install -e ".[full]"

# Load skills and run the pipeline
from mathmod_pilot.core import MathModPilotAgent

agent = MathModPilotAgent()
print(agent.list_skills())
# ['brainstorming', 'data-processing', ..., 'systematic-debugging']

# Run the full S0 → S7 pipeline
results = agent.run_pipeline({
    "problem_text": "2023 CUMCM Problem A: ...",
    "data_path": "data.xlsx",
})
