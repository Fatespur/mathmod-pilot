Pipeline / 流水线

从题目到论文，逐阶段推进

Move from prompt to paper, stage by stage

每个技能接收前序阶段产生的上下文，并将结构化结果继续传递。核心 Agent 不硬编码技能，新增目录即可扩展能力。

Each skill receives the context produced upstream and passes structured results forward. The core agent hard-codes no skills, so a new folder can extend the system.

S0

Brainstorming

澄清目标、约束、输出和整体执行路线。

Clarify goals, constraints, outputs and the execution route.

S1

Problem Analyzer

拆解问题、识别题型、路由方法并生成硬断言。

Decompose the problem, route methods and generate hard assertions.

S2

Data Processing

加载多格式数据，完成清洗、校验与物理约束检查。

Load multi-format data, clean it and check physical constraints.

S3

MLE Solver

生成可执行模型代码，求解并进行迭代修正。

Generate executable model code, solve and iteratively revise it.

S4

Model Validation

执行灵敏度、不确定性、残差与稳健性分析。

Run sensitivity, uncertainty, residual and robustness analysis.

S5

SciPilot Figure

根据结果与论文任务路由高质量科研图表。

Route publication-grade figures from results and paper needs.

S6

Paper Writing

以 CUMCM 中文或 MCM 英文模式组织竞赛论文。

Draft contest papers in CUMCM Chinese or MCM English mode.

S7

Paper Review

按照九维标准进行终审、定位缺陷并给出修复路径。

Perform a nine-dimension final review and route repairs.

Core mechanism / 核心机制

不只生成答案，还验证答案

Do not merely generate an answer—verify it

Generate–Verify–Revise

求解器在代码生成后执行硬断言、物理一致性与结果合理性检查；失败信息回流至生成阶段，直至通过或达到迭代上限。

After code generation, the solver checks hard assertions, physical consistency and result plausibility. Failures flow back into generation until the checks pass or the revision limit is reached.

Generate生成模型与代码Produce model and code
→
Verify执行与多层校验Execute and validate
→
Revise反馈错误并修正Feed back and repair
未通过 → 错误轨迹返回 Generate
Failure → error trace returns to Generate

Quickstart / 快速开始

安装后即可发现并运行技能

Discover and run skills immediately after installation

项目要求 Python 3.10+。可仅安装核心能力，也可按 solver、viz、validation 等 extras 选择科学计算依赖。

The project requires Python 3.10+. Install only the core, or select scientific dependencies through solver, viz and validation extras.

  • 动态列出当前可用技能
  • List currently available skills dynamically
  • 单独调用某项能力或运行完整流水线
  • Invoke one capability or run the complete pipeline
  • 通过统一字典传递题目、数据路径与中间结果
  • Pass prompts, data paths and intermediate results through one dictionary
quickstart.py
# Install the core package
pip install -e .

from mathmod_pilot.core import MathModPilotAgent

agent = MathModPilotAgent()
print(agent.list_skills())

results = agent.run_pipeline({
    "problem_text": "Optimise a transport network...",
    "data_path": "data.xlsx",
})

for name, output in results.items():
    print(name, output.get("status", "n/a"))
