# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-17

### Initial Release
- **Standardized Toolkit Architecture**: Packaged 15 competition-tested mathematical modeling skills across 9 lifecycle stages (S0 through S7).
- **Core Methodology Preservation**: Retained 100% of mathematical formulation rules, anti-template screening, independent sensitivity gates, and publication-ready plotting recipes.
- **Academic Method Architecture Engine**: Included `cumcm-academic-flowchart` with dual-stream, swimlane, and loop diagram generation (draw.io, SVG, PNG).
- **Markdown-Only Paper Pipeline**: Pure Markdown writing system with Word-native OMML equation integration and strict CUMCM format compliance validator.
- **Unified Registry**: Added `registry/skills.json`, `registry/skills.yaml`, and `registry/workflow.json` for agent automated discovery and DAG execution.
- **Interactive Visual Website**: Modern, high-performance website built with Vite + React + TypeScript + Tailwind CSS for exploring skills, inspecting artifacts, and previewing pipelines.
- **Decoupled CLI Utilities**: Completely decoupled from host environments; sanitized absolute paths and eliminated external dependencies.
