# HYBRID_MODELING validation contract v2

Mandatory: same-split best-single-component baseline; full-vs-ablation materiality; interface schema/timing/leakage audit; uncertainty propagation into decision loss; component and end-to-end calibration; split/seed/policy stability; interface shift/failure tests. Material full-system improvement is release-eligible only when all R2 checks also pass; this pack never releases it.
