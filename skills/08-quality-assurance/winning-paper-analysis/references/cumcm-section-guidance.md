# 第一部分：国一与国二的本质差距

## 1.1 数据对比

| 维度 | 国一 | 国二 |
|------|------|------|
| 获奖率 | 0.5%-0.61% | 2.3% |
| 论文页数 | 20-25页 | 15-20页 |
| 公式数量 | 30+条 | 15-25条 |
| 图表数量 | 15-20张 | 8-12张 |
| 参考文献 | 10-15篇 | 5-8篇 |
| 摘要打磨时间 | 3-5小时 | 1-2小时 |
| 核心差异 | 读得懂、想得深、写得细 | 框架完整但缺乏深度 |

## 1.2 国一论文的六大"降维打击"特征

**特征一：问题分析"细腻入微"**
国一论文对问题分析特别细腻，不是简单罗列子问题，而是对每个子问题做**数学本质的深度剖析**。国二论文往往"走框架感"——问题分析→模型建立→模型求解→结果分析，像流水线。国一论文让你"读明白读懂"，对问题思考全面，细节到位。

**特征二：模型建立"有理有据"**
国一论文不堆砌模型，而是每个模型的选择都有"为什么选A不选B"的论证。模型推导写出中间步骤，不只写最终公式。求解得到的结果与生活实际情况相符——如果不符合，会主动修正模型。

**特征三：公式密度高且解释充分**
国一论文公式不少于25条（通常30+条），但不会"一堆公式砸下来"。每个公式后跟1-2句文字解释，公式间穿插文字叙述和图表。公式多意味着模型看起来复杂、有深度。

**特征四：图表丰富且有深度**
国一论文图表15-20张，包含三维图、效果图、热力图等"高级图表"。示意图不只是"画个框图"，而是真正结合题目变量和步骤定制的。每张图都有清晰的图题，图后跟3-5句分析。

**特征五：检验全面且分析深入**
国一论文的检验包含：拟合优度（R²、RMSE、MAE）+ 残差分析（残差图+正态性检验）+ 交叉验证（不同数据集/方法对比）+ 灵敏度分析（4-6参数）+ 不确定性分析（蒙特卡洛/Bootstrap）。如果检验结果不理想，会给出合理解释而不是回避。

**特征六：排版"赏心悦目"**
图文穿插、善用三线表、分段清晰、公式居中编号右对齐。图片清晰（线条和字体加大加粗），不用截图工具，用代码导出。段落长短适中，不会出现大段文字或大片空白。

# 第二部分：CUMCP 获奖论文章节级精析

## 1. 摘要——决定80%的评奖结果

**核心定位**：摘要是论文的门面。一个摘要+结果基本可以决定你是省一以上还是省二、三。评委看摘要的时间约为2分钟，这2分钟决定是否继续细读。

**篇幅**：独立成页，0.8-1页（约500-800字），尽可能满页。

**是否分点**：**不分点**。摘要必须是连续段落，段落间空行，让摘要看起来更整洁。

**结构公式**（国一论文标准模式）：
```
[第一段：问题引入]
1-2句，对所要解决的问题作阐述。不要照抄原题中的话（避免查重+避免千篇一律）。
从实际应用角度切入，让评阅老师感受到你"理解了这个问题的意义"。

[第二段：问题1]
针对什么问题，提出什么方法（运用什么模型、采用何种算法），得到什么结果（能用数值最好用数值）。
对主要模型和算法进行**加粗**，以便凸显工作。

[第三段：问题2]
同上结构。每个子问题独立成段。

[第四段：问题3]
同上结构。

[第五段：特色概括]
对本文的特色作概括：什么模型与什么模型结合，是否有可视化，灵敏度分析的结果，
稳定性，求解的精确性，算法的复杂度等。这段提升老师对你论文的期许。
```

**获奖论文关键模式**：
- 每个子问题必须包含：**用了什么方法 + 得到什么结果 + 具体数值**
- 数值必须精确到有效数字（如 8.10 μm 而非"约 8 μm"）
- 对主要模型和算法名称**加粗**，便于评委快速定位
- 不出现图表引用、公式编号、参考文献
- 关键词 4-6 个，涵盖：问题是什么、主要模型 2-3 个、算法 1-2 个、灵敏度分析
- 摘要需要**三人一起讨论修改至少 3 小时**，反复打磨

**常见错误**：
- 只写方法不写结果数值（最致命）
- 照抄原题中的话（千篇一律+查重风险）
- 使用"较好结果""令人满意"等模糊表述
- 摘要超过 1 页或不足 0.5 页
- 关键词过多或过少（<3 个或 >8 个）
- 忘记加粗关键模型和算法名称

**好摘要 vs 差摘要对比**：
```
差：针对问题1，建立了干涉模型，采用FFT方法计算了厚度，得到了较好的结果。
好：针对单次反射干涉问题，建立了**双光束干涉模型**，采用**FFT法**将波数域转换到
    光程差域，计算得到SiC外延层厚度为**8.10 μm**，两种入射角（10°和15°）交叉
    验证偏差仅**0.28%**，结果高度一致。
```

## 2. 问题重述——展示理解深度

**核心目的**：展示对题目的理解深度，用自己的话重新组织问题。把阅卷老师引导到自己的思路中，把他们看成"不懂本问题的读者"。

**篇幅**：0.5-1 页

**是否分点**：**是**。问题提出部分按子问题分点（问题 1、问题 2、问题 3），每个子问题用编号列表。

**结构公式**：
```
[2.1 问题背景]：3-5 句
从"为什么这个问题重要"的实际应用角度切入，而非简单复述赛题背景。
提及数据特征（如"包含波数范围 399.67-4000.12 cm⁻¹ 内的 7469 个测量点"）。

[2.2 问题提出]：按子问题逐一列出
每个子问题 2-3 句，指出数学本质，用自己的语言重新组织。
格式：**问题X：** [数学本质]。需要[做什么]。
```

**获奖论文关键模式**：
- 背景部分从实际应用角度引出问题意义，而非简单复述赛题背景
- 每个子问题指出其**数学本质**（如"本质是参数反演问题""本质是Fabry-Perot多光束干涉理论分析"）
- **不照搬赛题原文**，用自己的语言重新组织
- 提及数据特征（具体数值），展示你对数据的了解
- 问题提出部分的语言要"数学化"，展示你已将实际问题转化为数学问题

**常见错误**：
- 直接复制赛题原文（查重+千篇一律，双重扣分）
- 背景过长（超过 5 句）或过短（1 句带过）
- 没有指出数学本质，只是在复述问题
- 问题提出部分与问题分析部分内容重复

## 3. 问题分析——展示结构化分解能力

**核心目的**：展示结构化分解能力，说明选择方法的理由。这是国一论文区别于国二论文的第一个关键节点。

**篇幅**：0.5-1 页

**是否分点**：**分点**。每个子问题单独成段，加小标题（如"问题1的数学本质是..."）。

**结构公式**：
```
[3.1 问题本质分析]：每个子问题 1 段
- 分析数学本质：这是哪类数学问题？
- 列出 1-2 种可选方法，说明各自的优缺点
- 明确选择理由："为什么选 A 不选 B"
- 指出各子问题之间的关联和数据传递关系

[3.2 分析流程图]：1 张流程图
- 展示整体分析框架
- 包含数据流向、方法选择、模型间关系
- 使用 mermaid 或专业流程图
```

**获奖论文关键模式**：
- 每个子问题给出 1-2 种可选方法，并说明选择理由（"FFT法优于极值法，因为FFT对随机噪声具有积分平滑效应，且无需逐峰识别"）
- 使用流程图展示整体分析框架（不是简单的框图，而是真正结合题目变量和步骤）
- 明确指出各子问题之间的关联和数据传递关系
- 分析方法选择时说"为什么选 A 不选 B"，展示批判性思维

**常见错误**：
- 只列方法不说明选择理由（国二论文通病）
- 没有流程图（或流程图过于简单，只是"框图"）
- 问题分析过于简单（<0.3 页），等于没有分析
- 问题分析与问题重述内容重复

## 4. 模型假设与符号说明——为模型建立合理边界

> **v3 更新：** 国赛论文结构中，模型假设（三）和符号说明（四）已拆分为独立的两章，分别用三线表呈现。但写作逻辑和篇幅要求不变。

**核心目的**：为模型建立合理边界，定义所有符号。假设是"最关键的一步从假设开始"，需要下很大功夫。

**篇幅**：1-1.5 页

**是否分点**：**用表格**。假设和符号都用三线表呈现，不用列表。

**假设表格模板**：
```
| 编号 | 假设内容 | 理由与影响 |
|------|---------|-----------|
| 1 | [假设内容：数学化表述] | [为什么合理]。[如果违反]会[什么影响] |
```

**获奖论文关键模式**：
- 假设数量：5-8 条（太少显得模型太简单，太多评委记不住）
- 每条假设必须包含：**假设内容（数学化表述）+ 合理性说明 + 违反假设的影响**
- 假设要**数学化**，重视逻辑性要求。不能只是"假设xx是常数"，要说明"为什么可以假设是常数"
- 符号表按类别分组：物理量、模型参数、统计指标
- 符号表包含 20-30 个符号，覆盖全文所有公式
- 设计好符号，使人看起来清楚（符号要有一致性，如 d 表示厚度，n 表示折射率）

**常见错误**：
- 假设没有说明理由和影响（"假设xx=0"——为什么？违反了会怎样？）
- 符号表过于简单（<15 个符号），后面公式中突然出现未定义的符号
- 没有使用三线表格式
- 假设过多（>10 条）或过少（<3 条）

## 5. 模型建立与求解——核心建模能力展示

**核心目的**：展示核心建模能力，这是论文篇幅最大的部分。**国一论文要求一般设计 2-3 个模型**（一个简单的、再对模型进行改进，得到第二个模型，就会生动）。

**篇幅**：每个子模型 2-3 页，总计 6-9 页

**是否分点**：**混合**。公式推导用连续段落，算法步骤用编号列表，结果用表格。

**结构公式**（每个子模型）：
```
[X.1 问题X：标题]
    [X.X.1 问题分析]：0.2-0.3 页
    结合本题具体变量，重新分析这个子问题的数学本质
    
    [X.X.2 模型建立]：0.5-1 页
    公式推导（含中间步骤），每个公式后跟 1-2 句解释
    公式间穿插文字叙述，不要一堆公式砸下来
    物理意义清晰，数学推导严谨
    
    [X.X.3 模型求解]：0.3-0.5 页
    算法描述 + 结合本题变量的流程图
    算法步骤用编号列表（1-5 步），每步 1-2 句
    
    [X.X.4 结果分析]：0.5-1 页
    结果表格（完整数据，不只展示最终结果）
    + 图表（每个模型至少 1 张图）
    + 3-5 句文字分析（每个图表后）
```

**获奖论文关键模式——公式推导的黄金法则**：
- 全篇公式不少于 25 条（国一论文通常 30+ 条），公式多模型看起来就会显得复杂
- 公式推导写出**中间步骤**，不只写最终公式。展示"你是怎么想到的"
- **每个公式后跟 1-2 句文字解释**，说明公式的物理意义或数学含义
- 公式间穿插文字叙述和图表，不能让读者"看不懂公式怎么来的"
- 公式全文统一编号 (1), (2), (3)...（国赛硬性要求）
- 正文引用使用"式(1)"或"公式(1)"
- 说明建模的思路："有些简单的事情往往是最重要的东西，一定要说清楚"
- 刚开始的原始想法很重要，展示建模的思考过程

**获奖论文关键模式——算法描述的黄金法则**：
- 算法描述使用编号列表（1-5 步），每步 1-2 句
- 算法流程图：**每个模型至少 1 张图**，且**必须结合本题变量**，不能放通用流程图
- 编程手需将算法步骤解释给论文手：为什么要用这个算法？原理是什么？结合本题的步骤是什么？
- 说明模型的定性：线性或非线性？连续、离散或混合？时变或非时变？

**获奖论文关键模式——结果分析的黄金法则**：
- 结果表格展示**完整数据**，不只展示最终结果
- 每个图表后跟 3-5 句文字分析，不能只放图不分析
- 图表引用使用"如图 X 所示""由表 X 可知"
- 图表配色：蓝色系为主，橙色系为辅，灰色系为背景
- 图片分辨率不低于 300dpi

**常见错误**：
- 公式推导跳跃太大，缺少中间步骤（评委看不懂）
- 公式后没有文字解释（"一堆公式砸下来"）
- 图表后没有分析文字（"只放图不分析"）
- 算法流程图是通用的，没有结合本题变量
- 每个模型篇幅 < 1.5 页（不够充实，显得模型太简单）
- 公式数量 < 20 条（显得模型不够复杂）
- 建模手和编程手没有把思路解释清楚给论文手

## 6. 模型检验——区分优秀论文的关键

> **v3 更新：** 国赛论文结构中，模型检验独立成章（六），包含拟合优度检验、残差分析、灵敏度分析、不确定性分析和方法一致性检查。不再与灵敏度分析合并命名。

**核心目的**：这是区分国一和国二的关键章节，展示严谨性。**有就是加分项，做得好就是国一的标志**。

**篇幅**：2-3 页

**是否分点**：**分点**。检验和灵敏度分别成节，每个参数分析单独成段。

**结构公式**：
```
[6.1 模型检验]：1-1.5 页
    - 拟合优度检验（R², RMSE, MAE）——至少 2 种指标
    - 残差分析（残差图 + 正态性检验）——必须有图
    - 交叉验证（不同数据集/方法对比）——展示模型可靠性
    - 如果检验结果不理想，给出合理解释（不要回避）

[6.2 灵敏度分析]：1-1.5 页
    - 4-6 个参数的灵敏度分析
    - 每个参数配一段文字说明 + 1 张图
    - 灵敏度系数用表格汇总
    - 说明哪个参数是主导因素，为什么

[6.3 不确定性分析]：0.5-1 页
    - 蒙特卡洛模拟（建议 5000+ 次）或 Bootstrap
    - 给出 95% 置信区间和变异系数（CV）
```

**获奖论文关键模式——灵敏度分析的标准做法**：
- 灵敏度分析的定位：**对模型假设中的参数做上下变化，分析对结果的影响**
- 常见于优化或预测类问题，但在物理建模中同样重要
- 至少 4 个参数，每个参数配一段文字说明 + 1 张图
- 灵敏度系数用表格汇总，一目了然
- 灵敏度分析不需要很复杂，但必须有——"有就是加分项"
- 国一论文的灵敏度分析也并不是做得特别复杂，关键是**到位、完整**

**获奖论文关键模式——模型检验的多种方法**：
- 多种检验方法并用（至少 3 种：R² + RMSE + 残差分析）
- 如果检验结果不理想，给出合理解释（展示批判性思维，比回避好得多）
- 交叉验证：不同数据集/方法的结果对比，展示一致性
- 稳定性检验：对模型输入做微小扰动，观察输出变化

**常见错误**：
- 只有一种检验方法（R² 就完事了）
- 灵敏度分析参数太少（< 3 个）
- 灵敏度分析没有图表（"只说不画"）
- 没有不确定性分析（缺少置信区间）
- 检验结果不理想却回避不谈（评委一眼看出）

## 7. 模型优缺点评价——展示反思能力

> **v3 更新：** 国赛论文结构中，模型优缺点评价独立成章（七），包含三个子节：7.1 模型优点、7.2 模型缺点、7.3 模型改进。

**核心目的**：展示反思能力，客观评价模型。"不能光夸自己，模型不对的地方也要说出来"。"想到模型的不足但没有改进"比"没想出模型的不足"好得多。

**篇幅**：1 页

**是否分点**：**分点**。优点和缺点各用编号列表。

**结构公式**：
```
[7.1 模型优点]：4-5 条
每条用数据支撑，不能空泛。
覆盖：建模深度、计算精度、方法创新、可推广性、数据利用

[7.2 模型缺点与改进方向]：3-4 条
每条配改进方法，不能只说"xx不够好"。
覆盖：模型简化、数据质量、计算复杂度、参数敏感性
```

**获奖论文关键模式**：
- 优点必须有数据支撑（"精度高"→"交叉验证偏差仅 0.28%"）
- 缺点必须配改进方法（"折射率做了常数近似"→"可采用 Sellmeier 色散方程描述折射率-波长关系"）
- 优点 4-5 条，缺点 3-4 条（数量对称，不能优点一大堆缺点一条）
- 优点覆盖：建模深度、计算精度、方法创新、可推广性、数据利用
- 缺点覆盖：模型简化、数据质量、计算复杂度、参数敏感性
- 改进方向不要玩弄新数学术语，要具体可行

**常见错误**：
- 优点空泛，没有数据支撑（"模型精度高""方法有创新"——具体数字呢？）
- 缺点没有改进方向（"折射率取值不够精确"——怎么改进？）
- 优缺点数量不对称（5 条优点配 1 条缺点）
- 改进方向过于空泛（"未来可用深度学习"——怎么用？）

## 8. 结论——总结全文贡献（CUMCM v3 已取消独立章节）

> **v3 更新：** CUMCM 论文结构中，结论不再作为独立章节。结论内容融入摘要和各模型的结果分析（5.1.5）中。MCM/ICM 论文仍保留 Conclusion 章节。

**核心目的**：总结全文贡献，呼应摘要。数值与摘要保持一致（否则评委发现不一致会扣分）。

**篇幅**：0.5-1 页

**是否分点**：**分点**。每个子问题结论用编号列表。

**结构公式**：
```
[总体概述]：1-2 句，总结论文做了什么
[问题1结论]：1-2 句，方法+结果+数值
[问题2结论]：同上
[问题3结论]：同上
[推广展望]：1-2 句，方法可推广至哪些领域
```

**获奖论文关键模式**：
- 每个子问题 1-2 句，包含方法+结果+数值
- 数值与摘要**绝对一致**（评委发现不一致会认定论文不严谨）
- 结尾有推广展望（"本文的方法可推广至其他半导体材料（如GaN、GaAs）的外延层厚度测量"）
- 不引入新内容（结论中不应出现正文未讨论过的模型或数据）

**常见错误**：
- 结论与摘要数值不一致（致命错误）
- 结论过于简短（<0.3 页，等于没写结论）
- 引入新数据或新模型（结论不是讨论章节）

## 9. 参考文献——展示学术规范性

**核心目的**：展示学术规范性。参考文献 10 篇左右，尽量少引用网络资源。

**篇幅**：0.5 页

**格式**：GB/T 7714

**数量**：8-15 篇（推荐 10 篇左右）

**获奖论文关键模式**：
- 数量：8-15 篇（推荐 10 篇左右）
- 类型：教材 1-2 本、期刊论文 4-6 篇、专著 1-2 本、标准/手册 1-2 份
- 正文中所有引用必须有对应参考文献
- 引用标注在右上角用方括号标示参考文献编号
- 尽量少引用网络资源
- 参考文献按正文中引用次序列出

**常见错误**：
- 参考文献 < 8 篇（显得学术基础薄弱）
- 格式不统一（有的 GB/T 7714，有的 APA）
- 正文引用与参考文献列表不对应
- 大量引用网络资源

## 10. 附录——补充材料

**核心目的**：提供补充材料，不影响正文阅读。代码必须能运行，并且有实际意义。

**篇幅**：2-5 页

**是否分点**：**混合**。代码用代码块，数据用表格。

**获奖论文关键模式**：
- 代码必须带注释（按自己的理解对代码进行注释，说明逻辑和数值传递）
- 补充数据表要完整
- 附录不重复正文内容
- 核心代码放在附录，太复杂的计算过程也放在附录
- 代码要能运行，并且有实际意义（国一论文的代码一定可以运行）

**常见错误**：
- 代码无注释（评委看不懂）
- 附录过于简单（<1 页，等于没有附录）
- 与正文重复（降低信息密度）
- 代码不能运行
