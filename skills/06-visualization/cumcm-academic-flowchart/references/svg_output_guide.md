# SVG 输出

SVG 作为论文主格式，直接从 Scene Graph 生成，不依赖 draw.io Desktop。必须包含正确 `viewBox`、标准形状、原生路径、透明度、箭头 marker、多行 `<text>/<tspan>` 和 metadata。

支持圆角矩形、菱形、六边形、椭圆、圆柱、文档形状、分组容器、正交折线、箭头、轻微渐变和透明度。禁止：

- 嵌入整张位图冒充矢量；
- 远程字体、图片或不可移植资源；
- 裁切节点和箭头；
- 通过截图生成 SVG。

默认 `text` 模式保留可选中文字。请求 path 模式但没有可靠字体轮廓后端时，应保留 text 并明确报告降级。
