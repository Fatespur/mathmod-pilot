# 高级学术视觉语言

目标是成熟 SCI/EI/IEEE/Elsevier/Springer 方法框架图：层级明确、色彩丰富但受控、半透明填充、清晰边框、足够留白、可打印。禁止默认 SmartArt、白框黑箭头、商业海报、卡通信息图、高饱和互联网风和廉价装饰。

结构优先于装饰。优美来自模块比例、主次尺度、对齐、对称或有节奏的不对称、分支汇聚和留白，而不是增加颜色、图标或曲线。主方法应成为视觉锚点，子方法形成可辨识的组，验证与结果保持独立出口。

## 形状语义

- 一般处理：圆角矩形
- 数据输入：平行四边形/数据卡片
- 数据库：圆柱
- 判断：菱形
- 优化求解：六边形或强调卡片
- 核心模型：双边框卡片
- 结果：文档或结果卡片
- 分组：半透明容器
- 反馈：回转箭头或虚线

形状必须克制。禁止 3D、厚重阴影、发光、拟物按钮、卡通图标和大量装饰图标。

## 内容压缩

图片使用 `short_label`，详细解释放入生成报告。中文标签通常 4-14 字、最多三行、每行 10-12 字；长公式不塞入节点；优先“动词 + 对象”。缩写首次出现可给全称。
