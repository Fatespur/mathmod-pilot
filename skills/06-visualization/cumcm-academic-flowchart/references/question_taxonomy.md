# 国赛五类题型分类

## 索引

- 唯一主类别规则
- 五类判据
- 置信度与冲突

## 唯一主类别规则

每一小问必须且只能有一个 `primary_type`。依据最终输出目标分类，而不是依据中间使用的算法。回归既可用于预测，也可用于统计推断；出现回归不能自动归为预测类。

## 五类判据

| 类别 | 最终输出 | 关键语义 |
|---|---|---|
| 优化类 | 最优路径、方案、调度、配置 | 决策变量、目标函数、约束、求解、可行性 |
| 预测类 | 未来值、趋势、补全值、预测区间 | 时序方向、数据划分、训练、误差、泄漏控制 |
| 评价类 | 得分、等级、排序、优劣 | 指标、正向化、无量纲化、权重、综合评价 |
| 数理统计类 | 显著性、分布、置信区间、统计规律 | 样本、前提检验、统计量、区间、诊断 |
| 机理分析类 | 状态演化、物理机制、动力学规律 | 系统边界、状态/控制/外生变量、方程、初边值 |

分类记录至少包含 `question_id, primary_type, confidence, goal, inputs, outputs, auxiliary_methods, reason, uncertainties`。

## 置信度与冲突

- 没有明确输出目标：置信度不高于 0.50，并列出待确认项。
- 目标词与方法词冲突：目标词优先，方法放入 `auxiliary_methods`。
- 两类得分接近：仍选择唯一主类，同时在 `uncertainties` 记录备选解释。
- 不得为了图形完整而编造确定结论。
