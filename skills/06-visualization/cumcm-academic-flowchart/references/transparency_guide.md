# 透明度规范

默认范围：

| 元素 | alpha |
|---|---:|
| 普通节点填充 | 0.16-0.30 |
| 核心模块填充 | 0.24-0.38 |
| 分组底板 | 0.06-0.14 |
| 辅助区域 | 0.05-0.10 |
| 节点边框 | 0.75-1.00 |
| 主箭头 | 0.85-1.00 |
| 辅助箭头 | 0.40-0.70 |
| 正文文字 | 1.00 |
| 辅助文字 | 0.75-0.90 |

透明度主要用于填充，正文文字保持完全不透明，主箭头不能过淡。SVG 使用 `fill-opacity/stroke-opacity`；PNG 保留 alpha 通道。透明背景与彩色背景下都必须可读。
