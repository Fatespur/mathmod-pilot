# 字体与标签

字体回退顺序：

1. Microsoft YaHei
2. Noto Sans CJK SC
3. Source Han Sans SC
4. SimHei
5. Arial
6. sans-serif

不提交字体文件、不强依赖商业字体、不把全部文字转位图。SVG 默认保留 `<text>/<tspan>` 可选中文字；PNG 渲染前探测字体并将缺失写入警告。

默认论文目标宽度 160 mm。缩放后：

- 主节点不低于约 8.5 pt；
- 核心模块约 9.5-11 pt；
- 分组标题约 10-12 pt；
- 边标签不低于约 7.5 pt。

不得无限缩小字体容纳内容；应缩短标签、增加画布或拆图。
