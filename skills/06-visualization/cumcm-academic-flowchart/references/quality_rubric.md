# 五类检查与 100 分制

## 五类检查

1. **语义**：核心模型、主/子方法层级、最终输出、验证、小问依赖、变量/参数/目标/指标/约束/假设区分、明确方法名保留、无来源推断。
2. **几何**：重叠、越界、箭头穿节点/文字、交叉、裁切、容器、留白、比例。
3. **视觉**：颜色数量、相邻区分、透明度、对比度、重心、主辅层级、灰度打印。
4. **格式**：draw.io/SVG XML、viewBox、PNG 头/尺寸/alpha/非空、节点与文字一致。
5. **双布局**：节点和关键边一致、布局家族不同、备用非凑数、差异度达标。
